# Chattodo 产品功能目录树

> 本文按用户可感知的产品能力抽取，而不是按源码文件逐一罗列。结构分为“一级大纲”和“细化目录树”，便于先看全貌，再继续拆需求、排版本或补产品文档。

## 一级大纲

```text
Chattodo
├── 1. 截图采集与 AI 工单识别
├── 2. 待办 / 工单生命周期管理
├── 3. 时间线、附件与结论沉淀
├── 4. 辅助排查、案例检索与阶段总结
├── 5. 异步日志分析 Agent
├── 6. 项目主数据与项目关联
├── 7. 环境管理、访问凭据与 OTP
├── 8. 功能点自动匹配与工单补全
├── 9. 知识库归档
├── 10. 外部平台与脚本集成
├── 11. 控制面板与系统配置
├── 12. 本地存储、迁移与运行保障
├── 13. 通知、加载态与桌面体验
└── 14. 官网、文档与打包交付
```
